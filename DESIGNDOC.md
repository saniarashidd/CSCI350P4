* kalloc.c: Added refcount array that has one entry per physical page. modified kalloc to set a page count to 1 when it's first allocated. modified kfree to decrement the count and only free the page when the count hits 0. freerange sets each count to one so it can init properly. Added implementation for reference counting helper functions incref(), decref(), getref().
* mmu.h: Added PTE_COW flag for pages that are shared across processes and marked read-only so writes trigger a page fault instead of modifying shared physical memory directly.
* vm.c: Added implementation for cowuvm() (share the physical page and update flags to be read-only/CoW) and pagefault() which allocates a new physical page once a CoW page fault is triggered. When a shared page is released during deallocation or a CoW fault, cowupdate() makes the sole remaining mapping writable.
* trap.c: Add a case for CoW page faults in trap() to intercept them when they occur.

In testcow.c, malloc() allocates a buffer and fork() creates a child process that initially shares the parent's pages as read-only (n) Copy-on-Write mappings instead of copying them right away. The program dumps page mappings before fork(), right after fork() before modifying memory, and after the child increments every byte in the buffer. Sharing the same physical frames with n right after fork() proves fork() avoids immediately copying. When the child writes to the buffer, page faults allocate new physical frames for the modified pages and mark them writable (y) for the child, confirming CoW works. When one process releases a shared page, the remaining process's mapping is immediately promoted to writable if its reference count shows it is the sole owner.
